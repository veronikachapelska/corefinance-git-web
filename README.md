## Про проєкт

CoreFinance Suite - інформаційна система фінансової компанії для автоматизації кредитування: заявка, скоринг, графік платежів, підписання договору, прострочення та звітність НБУ.

## Структура репозиторію

- index.html - вебсторінка-візитка системи
- README.md - опис проєкту

- main - основна стабільна гілка
- feature - розробка розділу "Кредитний калькулятор", PR #1
